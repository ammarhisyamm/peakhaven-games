# Game covers and Sequence specials

The Play page now shows Peak Blocks' board and tray, Sequence's crystal grid and line blast, and Ridge Run's crystal orb between vial gates. These are promotional illustrations; all scores, instructions and actions remain live UI. Card spacing and responsive layouts are preserved. Versioned WebP filenames avoid stale cover caches.

Sequence uses generated transparent art for its specials:

- Four-match: silver crystal rails over the original gem colour, pointing along the clear direction. A horizontal four still creates a column blast; a vertical four still creates a row blast.
- Wrapped crystal: an open-centre gold/silver harness over the original gem.
- Colour bomb: a multicoloured prismatic orb.

Sprites preload with the ordinary gems. The original canvas markers remain the fallback if artwork cannot load. Animation alpha, scoring, objectives, combos and replay rules are unchanged.
